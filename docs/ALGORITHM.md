# 算法语义

本文档描述 haplotyper 的分相模型、冲突裁决策略、块划分规则、置信度计算、
家系语义与确定性保证。

## 1. 基本概念

- 位点经 `(染色体, 位置, ID)` 排序得到规范顺序 `v0 < v1 < ...`。
- 每个样本的基因型分为：纯合 ref（`0/0`）、纯合 alt（`1/1`）、杂合（`0/1`）、
  部分缺失（`0/.`、`./1`）与完全缺失（`./.`）。只有完全已知的杂合位点需要分相。
- 对杂合位点定义一个二元变量 `x_v ∈ {0,1}`，表示 `h1` 单倍型在该位点携带的等位；
  则 `h2 = 1 - x_v`。

## 2. 读段证据：相邻杂合位点的奇偶约束

同一条读段上的所有等位来自同一个分子。对一条读段覆盖的两个在样本中“相邻的杂合位点”
`vi, vj`（二者之间没有该样本的其他杂合位点）：

- 观测等位相同（同为 0 或同为 1）⇒ 投票 `same`：`x_vi XOR x_vj = 0`。
- 观测等位不同 ⇒ 投票 `flip`：`x_vi XOR x_vj = 1`。

不相邻的杂合位点（中间隔着其他杂合位点）不直接产生边；跨越纯合/缺失位点不影响
“相邻杂合位点”的定义。

所有约束通过加权（异或）并查集（`dsu.go`）求解，等价于一个二元线性方程组；
路径压缩与按秩合并保证近线性复杂度。

## 3. 读段-读段冲突裁决

每条边分别累计 `same` 与 `flip` 的独立读段票数：

1. 多数票决定奇偶性。
2. 票数相等时按固定策略裁决，绝不静默丢弃、绝不随机取舍：
   - `seed_enabled=false`（默认）：取参与该边的最小 `read_id` 所投奇偶。
   - `seed_enabled=true`：用确定性 PCG 伪随机数生成器，以
     `random_seed + 样本序号*1000003 + 边序号` 为流，取 0/1。同种子完全可复现。
3. 每条投票给被否决奇偶的读段都计入 `read_read_conflicts`，并在 `entries[]` 中
   记录样本、读段、相邻位点、`voted_parity` 与 `kept_parity`。

此外，读段在已知纯合位点观测到相反等位（如 `0/0` 位点读到 `1`）属于读段与基因型的
直接矛盾：该观测被拒绝投票、计入 `read_genotype_conflicts` 并在 `entries[]` 中留痕，
不会被静默丢弃。

## 4. 边置信度与块划分阈值

给定每条观测的错误概率 `e = read_error_rate`，在两种奇偶性等先验下，后验为：

```
P(flip | nFlip, nSame) ∝ (1-e)^nFlip · e^nSame
P(same | nFlip, nSame) ∝ (1-e)^nSame · e^nFlip
```

在对数空间归一化，取获胜奇偶的概率作为该边的 `confidence`。

一条边被接受、从而连接两个相邻杂合位点，当且仅当同时满足：

- `nFlip + nSame >= min_edge_support`
- `confidence >= min_block_confidence`

任一条件不满足即在该位置**确定性地断开分相块**。未被任何接受边连接的杂合位点为
未分相（`unphased`），`block_id=0`。

块内全局方向（整体交换 h1/h2 的二义性）以“块内规范顺序最小的杂合位点 `h1=0`”锚定，
与并查集根的选择无关，因此方向也是确定的。

## 5. 块置信度与预期错误率

一个块的置信度为块内相邻杂合位点各边后验置信度之积：

```
block_confidence   = Π edge_confidence
expected_error_rate = 1 - block_confidence
```

浮点结果四舍五入到 12 位小数后写出，保证跨运行/跨主机字节稳定。

## 6. 三人家系语义

提供 `child/father/mother` 时：

### 6.1 逐位点孟德尔校验

对每个孩子位点，按父母基因型求其可传递等位集合（`0/0->{0}`、`1/1->{1}`、
`0/1->{0,1}`、`./{x}->{x}`、`./.->{0,1}`），枚举孩子两条未分相等位的两种来源顺序。
不存在任何可行父/母来源组合时，标记 `mendel_violation=true`：

- 该位点计数到 `trio_mendel_violations`。
- 强制输出为 `unphased` 并清除其块归属。
- 不计入 `correctly_phased`。

### 6.2 父源/母源等位与起源解析

孩子的两条单倍型必须一条来自父亲、一条来自母亲。当可行来源唯一时，确定
`paternal`/`maternal` 传递等位：

- 只要父亲或母亲任一方的传递等位可被唯一确定，孩子杂合位点即标记
  `origin_resolved=true`。
- 对同一条单亲本（仅父方或仅母方）在两个相邻杂合位点都被钉住的情况，
  其传递等位相同/不同即给出 `same/flip` 约束，可在无读段时扩展或建立块。
- 单个被家系钉住的杂合位点作为“单点家系块”输出，`h1` 为父源等位（父源未知时
  取母源等位的互补），并标记 `paternal_h1`。

### 6.3 家系优先于读段的冲突裁决

孩子的约束以“家系优先”重建：先加入全部家系约束，再加入已接受的读段边。
与家系矛盾的读段边被否决，计数到 `read_trio_conflicts`（明细 `kind="read_trio"`），
读段证据不会覆盖遗传约束，也不会被静默丢弃。

## 7. 缺失数据与低覆盖

- 完全缺失位点输出 `missing`（`h1=h2=-1`），部分缺失输出 `unphased` 并保留已知等位。
- 读段覆盖数 `< min_reads_per_site` 的非缺失位点标记 `low_coverage=true`，
  仍可因读段或家系证据被分相；不会因为缺失或低覆盖而中止处理。
- 所有位点（含未分相/缺失）都出现在输出中，结果完整可读、可直接用于下游分析。

## 8. 确定性与可复现

- 位点顺序、样本顺序、读段顺序、块编号与冲突明细排序全部确定。
- 相同输入与配置，多次运行输出逐字节一致。
- 启用 `seed_enabled` 时，平局由固定种子的 PCG 决定；同种子可复现，不同种子可能不同。

## 9. 输出回读（rephase）

`ReadResult` 会校验 `schema_version`；`Rephase` 校验位点坐标/ID、样本集合与已分相等位
与基因型相容。回读后按相同输入重跑流水线，并叠加先前结果中的分相赋值与块划分，
从而重新写出与原文件逐条、逐字节一致的结果。

## 10. 复杂度

设 `S` 为样本数、`V` 为位点数、`O` 为读段观测总数、`H_s` 为样本 `s` 的杂合位点数：

- 解析：对读段按 `(样本, 读段, 位点)` 排序，复杂度 `O(O log O)`，流式扫描内存有界。
- 分相：每样本并查集近线性 `O(H_s α(H_s))`；边数不超过 `H_s-1`。
- 总时间近 `O(O log O + Σ H_s α(H_s))`，随规模平稳增长。
