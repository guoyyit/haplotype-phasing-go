# 算法语义与冲突裁决

分相在样本间相互独立；处理顺序固定为样本首次出现顺序、位点文件顺序，
因此结果确定。

## 1. 位点分类

对每个“样本×位点”：

- 二等位杂合（倍性 2 且两个等位基因不同）才需要分相，记为杂合位点。
- 纯合、部分缺失（倍性 1）、完全缺失（倍性 0）不参与连边，但仍完整输出。
- 覆盖度 = 该样本覆盖该位点的有效读段观测数；低于 `min_site_depth` 标
  `low_cov=1`。低覆盖不会阻止分相，只做标记与计数。
- 部分缺失基因型（`A/.` 或 `./A`）保留观测到的等位基因，输出 `PARTIAL`；
  完全缺失（`./.`）输出 `MISSING`。缺失记号出现在任意一侧都按缺失处理。
- 基因型中出现的非 ref/alt 等位基因被拒绝（按缺失处理）并打印 `notice`，
  不会静默改写，也不会作为第三等位基因进入输出。

## 2. 读段边证据

一条读段覆盖的相邻杂合位点构成一条“边票”：

- 读段在两个相邻杂合位点观测到相同规范位（都为 A0 或都为 A1）→
  `same` 票（H1 相同相位）。
- 观测到不同规范位 → `opp` 票（H1 在第二位点翻转）。
- 只有“相邻杂合位点”（杂合序上的 h 与 h+1）形成直接边票；被纯合/缺失
  位点隔开的两个杂合位点不直接相连。

这一规则保证一条读段跨越的多个杂合位点全部成为同源归属证据。

## 3. 家系证据

提供 trio 时对子代逐位点处理：

1. 孟德尔相容性：子代两个等位基因必须能分别分配给父方与母方的一次传递，
   并考虑纯合子的剂量（如父 G/G、母 G/G 不可能生育 A/A 子代）。
2. 任何一方缺失（含部分缺失无法判定）都视为“信息不足”，不判违规。
3. 检测到违规：该位点 `violation=1`、状态 `UNPHASED`，不计入正确分相，
   且在杂合连锁图中摘除该位点（其两侧自然断块）。
4. 当孟德尔遗传可唯一确定父源等位基因（如父 A/A、母 G/G、子 A/G）时，
   记录该杂合位点 H1 必须携带父源等位基因；连续两个可唯一定向的位点
   追加一条带权家系边票（权重 `trioEdgeWeight=3`，见代码常量）。
5. 块内若存在强制父源位，则整块以此定向，保证子代两条单倍型分别继承自
   父方与母方；无强制位的块使用确定性默认定向（首位点 A0 置于 H1）。

家系从不随机取舍：违规与定向冲突都被计数（`trio_violations`、
`read_edge_conflicts`）。

## 4. 边裁决（确定性）

对每条相邻杂合边汇总 `same = readSame + trioSame`、
`opp = readOpp + trioOpp`：

- `same > opp`：多数方向为 same；`opp > same`：多数方向为 opp。
  - 少数票全部计为冲突并进入 `read_conflicts_adjudicated`；
  - 读段内部 self-conflict（同边同时存在 readSame 与 readOpp）计
    `read_edge_conflicts`；
  - 读段多数与家系多数方向相反，额外计一次跨源冲突。
- `same == opp`（完全平分，含 0:0 之外的等票）：不随机，调用
  SplitMix64(`seed`) 取一位决定方向，平局本身计为一次裁决冲突，
  并在统计中保留 `read_edge_conflicts`。
- 无任何证据：方向默认 same、强度 0、边错误率 0.5，不连通。

所有输入固定时，聚合与裁决顺序固定；`seed` 仅在等票平局时被读取，因此
改种子只可能改变平局方向，其余结果完全不变。

## 5. 断块阈值

边在同时满足以下全部条件时连通，否则断开（计入 `breaks_by_threshold`）：

- 总票数 `same + opp >= min_edge_support`；
- 多数强度 `max(same,opp)/(same+opp) >= min_edge_strength`；
- 边预期错误率 `<= block_max_error_rate`。

断开行为确定：相同输入与配置得到完全相同的块划分。

## 6. 置信度与预期错误率

边预期错误率采用对称 Jeffreys 先验 Beta(0.5,0.5) 的后验均值：

```
e = (conflict + 0.5) / (support + conflict + 1)
```

其中 support/conflict 是裁决后多数/少数票。无证据时 e=0.5。块级错误率把
块内各边视为相互独立的定向决策：

```
block_error = 1 - Π(1 - e_i)
block_confidence = 1 - block_error
```

SINGLETON 块没有内部边，错误率记 0、置信度记 1。低于
`min_block_confidence` 的多杂合块标 `LOW_CONF`（仍输出，可复核）。

## 7. 输出与往返

分相结果文件内嵌位点、基因型可重建信息、全部有效读段、家系与本次配置，
`-reread` 读入后重新分相并将结果逐字节与原文件比较，用于保证“输出可被
本服务重新读入并得到相同分相”。

违规位点的输出与回读语义：

- 违规杂合位点（`violation=1`）的 `h1`/`h2` 记录规范等位基因调用
  （`A0`/`A1`），使回读时能重建基因型；相位未知，仍为未分相。违规纯合
  位点记录纯合等位基因调用。
- 因此违规位点的标记、状态与全部统计计数在回读前后完全不变；违规的杂合
  位点与纯合位点均覆盖。
- 单倍型列中的缺失记号 `.` 只允许表示未分相或缺失状态；规范等位基因列
  始终等于位点文件的 ref/alt。

回读校验的验证方法：

- 校验通过的标准是重新生成的文件与原文件逐字节一致。
- 校验失败时输出首个不一致行的内容与行号（或兼容性错误的行号与位点 ID）。
- 修复前版本（`1.0`）产出的结果文件，包括其中违规杂合位点的行，执行回读
  校验时会返回明确的兼容性错误（`legacy phased file`）；请用当前版本重新
  运行分相生成可回读的文件。
- 使用 `examples` 目录下的示例输入完整运行并执行回读校验必须通过。

## 8. 统计字段（`#stats`）

| 键 | 含义 |
|---|---|
| samples / variants | 样本数 / 位点数 |
| hets_total | 全部样本杂合位点总数 |
| phased_hets / unphased_hets | 已分相 / 未分相杂合位点数（违规计入未分相） |
| blocks_total | 分相块总数 |
| read_observations | 有效读段观测总数 |
| read_pairs | 形成相邻杂合边票的读段对数 |
| read_edge_supports | 裁决后连通且有正向票的边数 |
| read_edge_conflicts | 读段内/读段–家系方向冲突次数 |
| read_conflicts_adjudicated | 经多数/平局策略裁决的冲突边数 |
| trio_count | 家系数 |
| trio_constraint_sites | 提供遗传约束的子代杂合位点数 |
| trio_violations | 孟德尔违规位点总数（含纯合违规） |
| breaks_by_threshold | 因强度/支持度/错误率阈值断开的边数 |
| low_coverage_sites | 低覆盖“样本×位点”数 |
| missing_genotypes | 完全缺失基因型“样本×位点”数 |
